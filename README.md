- **Focus:** business intelligence, data modeling and KPI governance.
- **Stack:** Power BI, SQL and data pipelines.

**Building a reliable foundation for analytics.**

Data integration and persistence workflows designed to support reporting, historical analysis and repeatable data consumption.

- **Stack:** Python, SQL and relational databases.
